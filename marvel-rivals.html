The Problem

Marvel Rivals has 40 heroes across three roles: Duelist, Strategist, and Vanguard. The question: can an ML model automatically tier heroes based purely on their in-game stats — without relying on community consensus or manual labels?

The challenge was that heroes across different roles aren't directly comparable. A Vanguard's damage stats will always be lower than a Duelist's — not because they're weaker, but because that's not their job. Naive clustering would produce role-biased results.

Approach
01

API Data Collection

Consumed the Marvel Rivals REST API with rate limit handling and URL encoding for heroes with special characters in their names. Built a modular collect.py script fetching live stats for all 40 heroes.

02

Role-Normalized Feature Engineering

Engineered 6 features: winrate, KDA, dps_norm, sup_norm, tank_norm, hit_rate. The key insight: damage, healing, and damage-taken stats were normalized within each role using GroupBy z-score transforms. This means a Vanguard's tankiness is compared against other Vanguards, not against Duelists.

03

KMeans Clustering

Applied KMeans (k=5) with StandardScaler preprocessing. Tiers automatically assigned by mapping clusters to S/A/B/C/D labels ranked by average cluster winrate — no hardcoded mappings, making the pipeline robust to data drift across game seasons.

04

Streamlit Dashboard

Deployed an interactive Streamlit dashboard displaying all 40 heroes with live API images grouped by predicted tier. Executed full Git branching and PR workflow throughout with commit messages, PR descriptions, and docstrings.

Known Limitation
Utility Heroes Are Systematically Underrated

Heroes like Rocket Raccoon and Storm consistently land in lower tiers despite being considered strong by the community. Raw stats don't capture team synergy, ability kit impact, or the value of enabling other heroes. The model isn't wrong — it's revealing a real limitation of stat-only approaches to hero evaluation. This is documented in the codebase rather than overridden with manual adjustments.
